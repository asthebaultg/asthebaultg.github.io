Quel test statistique choisir ?

Parcours guidé pour explorer les principales familles de tests statistiques, à partir de tes objectifs et de ton plan d’étude.

Outil d’orientation, pas de diagnostic automatique. Le choix dépend aussi du plan expérimental, des distributions, de l’indépendance des mesures, des effectifs, des valeurs manquantes et des hypothèses. Les seuils « n = 30 » du document d’origine sont des repères pédagogiques et non des règles de décision universelles.

Trouver un test adapté à son étude

Panorama des méthodes

Pour approfondir le résultat du questionnaire, retrouve ici les grandes familles de tests et des commandes courantes. Cette liste est indicative : vérifier les hypothèses et la documentation des outils avant l'analyse.

Test t à un échantillon

Quantitative · Une population

Comparer une moyenne à une valeur de référence.

À vérifier : Indépendance et distribution des observations (ou robustesse adéquate).

R : t.test(x, mu = mu0)
Python : scipy.stats.ttest_1samp(x, popmean=mu0)
Test z sur une moyenne

Quantitative · Une population

Comparer une moyenne à une norme lorsque la variance populationnelle est connue.

À vérifier : Cas relativement rare ; ne pas remplacer automatiquement t par z lorsque n ≥ 30.

R : (mean(x)-mu0)/(sigma/sqrt(length(x)))
Python : (np.mean(x)-mu0)/(sigma/np.sqrt(len(x)))
Test du signe

Ordinale / quantitative · Une population / appariée

Évaluer le signe des écarts à une médiane théorique ou entre mesures appariées.

À vérifier : Test fondé sur le signe ; les zéros et ex æquo exigent une gestion explicite.

R : binom.test(sum(x > m0), sum(x != m0), p=.5)
Python : scipy.stats.binomtest(sum(x>m0), sum(x!=m0), p=.5)
Wilcoxon signé à un échantillon

Ordinale / quantitative · Une population

Tester la localisation d’une distribution par rangs signés.

À vérifier : Hypothèses sur la symétrie des différences à la valeur de référence.

R : wilcox.test(x, mu=mu0)
Python : scipy.stats.wilcoxon(x-mu0)
Test t de Student indépendant

Quantitative · 2 groupes indépendants

Comparer deux moyennes de groupes indépendants.

À vérifier : La version classique suppose notamment l’homogénéité des variances.

R : t.test(x, y, var.equal=TRUE)
Python : scipy.stats.ttest_ind(x, y, equal_var=True)
Test t de Welch

Quantitative · 2 groupes indépendants

Comparer deux moyennes de groupes indépendants lorsque les variances diffèrent.

À vérifier : Généralement préférable à l’imposition systématique de variances égales.

R : t.test(x, y, var.equal=FALSE)
Python : scipy.stats.ttest_ind(x, y, equal_var=False)
Test t apparié

Quantitative · 2 mesures appariées

Comparer deux mesures dépendantes ou deux observations de mêmes personnes.

À vérifier : Examiner la distribution des différences individuelles.

R : t.test(x, y, paired=TRUE)
Python : scipy.stats.ttest_rel(x, y)
Mann–Whitney U (Wilcoxon rang-somme)

Ordinale / quantitative · 2 groupes indépendants

Comparer les distributions à partir des rangs entre groupes indépendants.

À vérifier : Ne teste pas toujours directement la différence de médianes.

R : wilcox.test(x, y, paired=FALSE)
Python : scipy.stats.mannwhitneyu(x, y)
Wilcoxon des rangs signés appariés

Ordinale / quantitative · 2 mesures appariées

Comparer des mesures appariées à l’aide des rangs signés.

À vérifier : Les différences doivent satisfaire les hypothèses de symétrie pour une interprétation en localisation.

R : wilcox.test(x, y, paired=TRUE)
Python : scipy.stats.wilcoxon(x, y)
ANOVA à un facteur

Quantitative · 3+ groupes indépendants

Comparer plusieurs moyennes de groupes indépendants.

À vérifier : Examiner les résidus et l’homogénéité ; prévoir des comparaisons post-hoc adaptées.

R : summary(aov(y ~ groupe, data=donnees))
Python : scipy.stats.f_oneway(g1, g2, g3)
ANOVA de Welch

Quantitative · 3+ groupes indépendants

Comparer plusieurs moyennes avec variances hétérogènes.

À vérifier : Post-hoc de Games–Howell à envisager selon le contexte.

R : oneway.test(y ~ groupe, data=donnees)
Python : statsmodels.stats.oneway.anova_oneway(data, groups=groupes, use_var="unequal")
Kruskal–Wallis

Ordinale / quantitative · 3+ groupes indépendants

Comparer plusieurs groupes indépendants sur des rangs.

À vérifier : Post-hoc de Dunn ajustés si comparaisons multiples pertinentes.

R : kruskal.test(y ~ groupe, data=donnees)
Python : scipy.stats.kruskal(g1,g2,g3)
ANOVA à mesures répétées

Quantitative · 3+ mesures appariées

Comparer plusieurs conditions mesurées sur les mêmes unités.

À vérifier : Vérifier notamment sphéricité, structure intra-sujet et corrections appropriées.

R : aov(y ~ condition + Error(id/condition), data=donnees)
Python : statsmodels.stats.anova.AnovaRM(donnees,"y","id",within=["condition"]).fit()
Test de Friedman

Ordinale / quantitative · 3+ mesures appariées

Comparer plusieurs conditions appariées au moyen de rangs.

À vérifier : Nécessite un plan en blocs ; post-hoc appariés ajustés si nécessaire.

R : friedman.test(y ~ condition | id, data=donnees)
Python : scipy.stats.friedmanchisquare(mes1, mes2, mes3)
Test de Quade

Ordinale / quantitative · 3+ mesures appariées

Alternative par rangs à Friedman avec pondération des blocs.

À vérifier : Vérifier les conditions et l’implémentation du package choisi.

R : quade.test(as.matrix(mesures))
Python : (bibliothèque spécialisée ou implémentation validée)
Test de Page (tendance ordonnée)

Ordinale / quantitative · 3+ mesures appariées

Tester une tendance monotone dans des conditions ordonnées appariées.

À vérifier : Hypothèse directionnelle ordonnée spécifiée avant analyse.

R : (package spécialisé, selon version)
Python : (implémentation spécialisée)
Test binomial exact

Dichotomique / proportion · Une population

Comparer une proportion de succès à une référence.

À vérifier : Une proportion provient de succès/essais et n’est pas une variable continue individuelle.

R : binom.test(succes, total, p=p0)
Python : scipy.stats.binomtest(succes, total, p=p0)
Test de deux proportions

Dichotomique / proportion · 2 groupes indépendants

Comparer deux proportions issues de groupes indépendants.

À vérifier : Approximations asymptotiques à vérifier ; alternatives exactes possibles.

R : prop.test(c(s1,s2), c(n1,n2))
Python : statsmodels.stats.proportion.proportions_ztest([s1,s2],[n1,n2])
χ² d’ajustement (conformité)

Nominale · Une population

Comparer des effectifs de catégories à des proportions théoriques.

À vérifier : Vérifier les effectifs attendus ; version exacte/simulation si nécessaire.

R : chisq.test(effectifs, p=proportions)
Python : scipy.stats.chisquare(effectifs, f_exp=attendus)
χ² d’indépendance / homogénéité

Nominale / dichotomique · 2+ groupes indépendants

Tester l’association de deux variables qualitatives dans un tableau de contingence.

À vérifier : Effectifs attendus, indépendance des unités et taille des cellules.

R : chisq.test(tableau)
Python : scipy.stats.chi2_contingency(tableau)
Test exact de Fisher

Nominale / dichotomique · 2 groupes indépendants

Tester une association dans un tableau 2×2, même avec petits effectifs.

À vérifier : Définir le tableau et l’hypothèse ; pour tableaux plus grands, méthodes spécialisées.

R : fisher.test(tableau)
Python : scipy.stats.fisher_exact(tableau)
Test de McNemar

Dichotomique · 2 mesures appariées

Tester une différence de proportions dans un tableau binaire apparié.

À vérifier : N’utiliser que les paires discordantes ; variante exacte si effectifs faibles.

R : mcnemar.test(tableau_paires)
Python : statsmodels.stats.contingency_tables.mcnemar(tableau_paires)
Test Q de Cochran

Dichotomique · 3+ mesures appariées

Tester des différences de proportions binaires sur trois conditions appariées ou plus.

À vérifier : Unité suivie à chaque condition et réponses binaires.

R : (R: DescTools::CochranQTest)
Python : statsmodels.stats.contingency_tables.cochrans_q(data)
Test de Bowker (symétrie)

Nominale · 2 mesures appariées

Étudier la symétrie d’une table carrée d’observations appariées multiclasse.

À vérifier : Alternative au cadre strictement dichotomique de McNemar.

R : (package spécialisé)
Python : (implémentation spécialisée)
Corrélation de Pearson

Quantitative · 2 variables

Évaluer la force et la direction d’une relation linéaire.

À vérifier : Examiner nuage de points, valeurs influentes et hypothèses d’inférence.

R : cor.test(x,y,method="pearson")
Python : scipy.stats.pearsonr(x,y)
Corrélation de Spearman

Ordinale / quantitative · 2 variables

Évaluer une relation monotone à partir des rangs.

À vérifier : Égalités, non-linéarité monotone et indépendance à considérer.

R : cor.test(x,y,method="spearman")
Python : scipy.stats.spearmanr(x,y)
Corrélation τ de Kendall

Ordinale / quantitative · 2 variables

Évaluer une association ordinale à partir des paires concordantes et discordantes.

À vérifier : Souvent utile avec petits échantillons et nombreux ex æquo (τ-b).

R : cor.test(x,y,method="kendall")
Python : scipy.stats.kendalltau(x,y)
Corrélation point-bisériale

Quantitative + dichotomique · 2 variables

Associer une variable quantitative et une variable binaire.

À vérifier : Équivalente à une corrélation de Pearson avec codage binaire approprié.

R : cor(x, as.numeric(groupe))
Python : scipy.stats.pointbiserialr(groupe,x)
Régression linéaire (simple / multiple)

Réponse quantitative · Prédiction

Modéliser une réponse quantitative à partir d’un ou plusieurs prédicteurs.

À vérifier : Examiner résidus, non-linéarités, multicolinéarité et validation.

R : lm(y ~ x1+x2, data=donnees)
Python : statsmodels.formula.api.ols("y ~ x1+x2",data=donnees).fit()
Régression logistique binaire

Réponse dichotomique · Prédiction

Modéliser la probabilité d’une réponse à deux modalités.

À vérifier : Éviter la séparation parfaite et valider calibration/discrimination.

R : glm(y ~ x1+x2, family=binomial, data=donnees)
Python : statsmodels.formula.api.logit("y ~ x1+x2",data=donnees).fit()
Régression logistique multinomiale

Réponse nominale · Prédiction

Modéliser une réponse nominale avec trois catégories ou plus.

À vérifier : Choix de la catégorie de référence, effectifs et diagnostics.

R : nnet::multinom(y ~ x1+x2,data=donnees)
Python : statsmodels.MNLogit(y,X).fit()
Régression logistique ordinale

Réponse ordinale · Prédiction

Modéliser une réponse ordonnée avec plusieurs modalités.

À vérifier : Tester l’hypothèse de cotes proportionnelles si modèle correspondant.

R : MASS::polr(y ~ x1+x2,data=donnees,Hess=TRUE)
Python : statsmodels.miscmodels.ordinal_model.OrderedModel(y,X,distr="logit").fit()
Régression de Poisson

Comptage · Prédiction

Modéliser un nombre d’événements par unité d’exposition.

À vérifier : Contrôler dispersion, zéros et éventuel terme offset.

R : glm(y ~ x + offset(log(exposition)),family=poisson,data=donnees)
Python : statsmodels.formula.api.glm("y ~ x",data=donnees,family=sm.families.Poisson()).fit()
Régression binomiale négative

Comptage · Prédiction

Modéliser des comptes en présence de surdispersion.

À vérifier : Évaluer le processus d’échantillonnage et les nombreux zéros.

R : MASS::glm.nb(y ~ x,data=donnees)
Python : statsmodels.formula.api.negativebinomial("y ~ x",data=donnees).fit()
Modèle linéaire mixte

Réponse quantitative · Mesures répétées / hiérarchiques

Tenir compte des observations imbriquées (participant·es, classes, périodes).

À vérifier : Définir effets fixes/aléatoires, structure et diagnostics du modèle.

R : lme4::lmer(y ~ condition+(1|id),data=donnees)
Python : statsmodels.formula.api.mixedlm("y ~ condition",donnees,groups=donnees["id"]).fit()
Équations d’estimation généralisées (GEE)

Réponses diverses · Mesures corrélées

Modéliser des réponses corrélées avec inférence populationnelle.

À vérifier : Spécifier la famille de distributions et la structure de corrélation.

R : geepack::geeglm(y ~ x,id=id,data=donnees,family=binomial)
Python : statsmodels.GEE(y,X,groups=id,family=sm.families.Binomial()).fit()
Test de Shapiro–Wilk

Quantitative · Diagnostic

Évaluer une hypothèse de normalité.

À vérifier : Un test non significatif ne prouve pas la normalité ; étudier les résidus et QQ-plots.

R : shapiro.test(x)
Python : scipy.stats.shapiro(x)
Test de Levene

Quantitative · Diagnostic

Évaluer l’homogénéité des dispersions entre groupes.

À vérifier : Définir la variante et ne pas décider du modèle sur cette seule p-valeur.

R : car::leveneTest(y ~ groupe,data=donnees)
Python : scipy.stats.levene(g1,g2,g3)
Test de Bartlett

Quantitative · Diagnostic

Évaluer l’égalité des variances sous hypothèses de normalité.

À vérifier : Sensible à la non-normalité ; Levene est souvent plus robuste.

R : bartlett.test(y ~ groupe,data=donnees)
Python : scipy.stats.bartlett(g1,g2,g3)
Test de Kolmogorov–Smirnov

Quantitative · Diagnostic

Comparer une distribution empirique à une distribution entièrement spécifiée.

À vérifier : Attention lorsque les paramètres sont estimés sur le même échantillon.

R : ks.test(x,"pnorm",mean=0,sd=1)
Python : scipy.stats.kstest(x,"norm",args=(0,1))
Test F de comparaison des variances

Quantitative · 2 groupes

Comparer deux variances sous fortes hypothèses de normalité.

À vérifier : Sensible aux valeurs extrêmes et à la non-normalité.

R : var.test(x,y)
Python : scipy.stats.f.cdf(np.var(x,ddof=1)/np.var(y,ddof=1), len(x)-1, len(y)-1)
Test par permutation

Divers · Selon protocole

Construire un test à partir de la distribution d’une statistique sous permutations valides.

À vérifier : L’échangeabilité découle du plan ; ne pas permuter naïvement des mesures répétées.

R : coin::independence_test(y ~ groupe,data=donnees)
Python : scipy.stats.permutation_test((x,y),statistic)
Bootstrap et intervalles de confiance

Divers · Estimation

Estimer l’incertitude d’une statistique par rééchantillonnage.

À vérifier : Choisir une stratégie valide pour dépendances, petits échantillons et plan d’étude.

R : boot::boot(donnees,statistic,R=2000)
Python : scipy.stats.bootstrap((x,),statistic)
Comparaisons post-hoc de Dunn

Ordinale / quantitative · Après Kruskal–Wallis

Comparer des groupes par rangs après une analyse globale.

À vérifier : Ajuster les comparaisons multiples (Holm, BH, etc.).

R : FSA::dunnTest(y ~ groupe,data=donnees,method="holm")
Python : scikit_posthocs.posthoc_dunn(donnees,val_col="y",group_col="groupe",p_adjust="holm")
Comparaisons post-hoc de Tukey

Quantitative · Après ANOVA

Comparer les paires de moyennes avec contrôle du risque familial.

À vérifier : Hypothèses de l’ANOVA classique ; alternatives si variances inégales.

R : TukeyHSD(aov(y ~ groupe,data=donnees))
Python : statsmodels.stats.multicomp.pairwise_tukeyhsd(y,groupe)
Comparaisons post-hoc de Games–Howell

Quantitative · Après ANOVA de Welch

Comparer des paires de moyennes avec variances inégales.

À vérifier : Vérifier l’implémentation et les degrés de liberté adaptés.

R : rstatix::games_howell_test(donnees,y ~ groupe)
Python : pingouin.pairwise_gameshowell(data=donnees,dv="y",between="groupe")
Correction de Holm / FDR (BH)

Valeurs p · Comparaisons multiples

Contrôler les erreurs dues aux tests multiples, selon l’objectif.

À vérifier : La procédure d’ajustement doit correspondre à la famille d’hypothèses.

R : p.adjust(p_values,method="holm")
Python : statsmodels.stats.multitest.multipletests(p_values,method="holm")
